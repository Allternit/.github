# Allternit

Allternit, the open source alternative: one workspace for you and your agents, on your own machine, with the models and subscriptions you already have. The repositories here are Apache 2.0, except allternit-tts (GPL-3.0).

## Products

- **Workspace**: [ai.allternit.com](https://ai.allternit.com) on the web, [m.allternit.com](https://m.allternit.com) on your phone
- **iPhone**: [allternit.com/app](https://allternit.com/app) · **Android**: [allternit.com/play](https://allternit.com/play)
- **Allternit Desktop** (Mac, Windows, Linux): [allternit.com/download](https://allternit.com/download) · `brew install --cask allternit/tap/allternit`
- **Gizzi Code**: `npm install -g @allternit/gizzi-code` · `brew install allternit/tap/gizzi-code` · [docs](https://docs.allternit.com/cli/overview)
- **Freeweights**: open models, free to download · [freeweights.allternit.com](https://freeweights.allternit.com)
- **Courses**: A://Labs · [labs.allternit.com](https://labs.allternit.com)
- **YouTube**: [youtube.com/@allternit](https://www.youtube.com/@allternit)

## Repositories

- [`allternit-platform`](https://github.com/Allternit/allternit-platform) — the core monorepo. Gizzi Code, the API, SDKs and services all live here, and Gizzi Code releases are published from it.
- [`desktop`](https://github.com/Allternit/desktop) — Allternit Desktop downloads.
- [`freeweights`](https://github.com/Allternit/freeweights) and [`studio-engines`](https://github.com/Allternit/studio-engines) — the Freeweights catalog, site and CLI, and the Freeweights Studio engine kit.
- [`homebrew-tap`](https://github.com/Allternit/homebrew-tap) and [`scoop-bucket`](https://github.com/Allternit/scoop-bucket) — package manager installs for macOS and Windows.
- [`allternit-tts`](https://github.com/Allternit/allternit-tts) — the Kokoro text-to-speech process used by Allternit voice, kept separate because it is GPL-licensed.
- [`gizzi-code`](https://github.com/Allternit/gizzi-code) — earlier Gizzi Code source and the Linux runtime binary used by Allternit's cloud computers. Current Gizzi Code releases are in allternit-platform.
